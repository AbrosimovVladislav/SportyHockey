# Roadmap

Здесь собираем версии и идём по ним. У каждой версии — свой файл с итерациями и пунктами. Нумерация итераций сквозная по проекту (1.x → 2.x → ... → N.x).

**Статусы:** ✅ готово · 🟡 в работе · (без иконки) — ещё не начато

**Навигация — 5 нижних табов:** **Команда**, События, Деньги, Профиль, Ещё. Раздел **«Команда»** (бывший таб «Состав») содержит секции: **Состав, Статистика, Медиа, Настройки команды, Заявки**. Версии v0.2–v0.3 закрывают этот раздел по секциям; **Тактика** вынесена в [post-MVP](roadmap/post-mvp.md).

## ✅ v0.5 — Финансы

Полноценный раздел «Деньги» для организатора: хаб с балансом-разбивкой и быстрыми действиями, четыре подэкрана (финансовый срез за период, балансы игроков, универсальные операции с фильтрами, аналитика с графиками и прогнозом), три bottomsheet'а ввода (оплата игрока, депозит, расход). Учёт без онлайн-оплат — только ручной ввод. Долги, переплаты, депозиты — не записи, а вычисляемые разрезы поверх единой ленты `finance_transactions`. Полная обкатка перенесена в v0.6 — тестируем всё MVP сразу после главного экрана.

Эпики:

- [Финансы (учёт + прогноз)](features/finances.md)

→ [roadmap/v0.5.md](roadmap/v0.5.md)

## v0.6 — Главная

Главный экран приложения (`/` — он же `/team`, первый таб «Команда»). Шапка с логотипом и названием команды, карточка ближайшего события (тренировка / игра — c учётом типа), 2×2 быстрых действия, блок «Ключевая статистика» с тремя табами (топ-5 игроков, последний матч, сводка команды + финансовый баланс). У игрока — те же блоки, отличается набор quick-actions. Закрывает разработку MVP. Полная обкатка перенесена в v0.7 как стартовая итерация полировки.

Эпики:

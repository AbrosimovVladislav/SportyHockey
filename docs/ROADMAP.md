# Roadmap

Здесь собираем версии и идём по ним. У каждой версии — свой файл с итерациями и пунктами. Нумерация итераций сквозная по проекту (1.x → 2.x → ... → N.x).

**Статусы:** ✅ готово · 🟡 в работе · (без иконки) — ещё не начато

**Навигация — 5 нижних табов:** **Команда**, События, Деньги, Профиль, Ещё. Раздел **«Команда»** (бывший таб «Состав») содержит секции: **Состав, Статистика, Тактика, Медиа, Настройки команды**. Версии v0.2–v0.3 закрывают этот раздел по секциям.

## 🟡 v0.2 — Состав

Секция **«Состав»** раздела «Команда»: три представления (список / звенья / Светлые-Тёмные), публичный профиль игрока (редактирование организатором), создание placeholder-игроков, дефолтные звенья и Light/Dark на уровне команды (копируются в событие при создании), статистика игроков по событиям. Плюс доводка раздела «События» (автоназвание, единый экран статистики, явка по факту, fullscreen, уведомления всей команде). Приватный профиль (игрок редактирует себя сам) — в v0.5.

# Эпик: Команда и игроки

## Цель
Базовое управление командой и её составом. На PoC — минимум, дальше — расширение.

## Фичи

### v0.1
- **Profile-экран.** Карточка user (avatar, имя, @username, chip роли) + карточка команды (название). Лого не показываем — вернёмся в v0.2.
- **Список игроков `/squad`.** Все члены из `team_memberships` через `GET /api/teams/me/members`. Аватарка + имя + @username + chip роли.
- **Invite-ссылка для игроков.** Кнопка «Скопировать ссылку приглашения» на `/profile` — видна только organizer'у. Формат `https://t.me/<BOT_USERNAME>?start=team_<uuid>`. Игрок жмёт → бот обрабатывает deeplink → создаёт `team_membership(role=player)` → отвечает приветствием с inline-кнопкой «Открыть Mini App».

### v0.2
- Лого команды (загрузка в Supabase Storage)
- Редактирование профиля команды (название, лого)
- Промоут игрока до организатора (только организатор → организатор)
- Удаление игрока из команды (kick)
- Площадки команды как раздел профиля (см. [venues.md](venues.md))

### v0.3
- Настройки команды (`/squad/settings`): название, лого, командная фотография, роли, дефолты для событий, опасная зона — итерация 41.
- Заявки и приглашения для организатора (`/squad/requests`) — итерация 42.

### v0.4 — Личный профиль игрока

Модель «один источник, два режима отображения»:
- **Источник данных** — запись в `users` + поля членства в `team_memberships`.
- **Личный профиль** (`/profile`, новое в v0.4) — то, что игрок видит у себя: полный набор полей, редактирование своих контактов/аватара/амплуа/номера, личная статистика и финансы по активной команде.
- **Публичный профиль** (`/squad/[user_id]`, уже есть с v0.2) — то, что другие участники команды видят:
  - для **другого игрока команды** — без sensitive-полей (статистика и общие данные есть, финансы скрыты);
  - для **организатора** — расширенный режим с финансами и возможностью редактировать поля игрока (нужно, когда сам игрок не пользуется приложением — например, голосует через бота).

Это не два профиля, а одно состояние с разными правами просмотра/редактирования.

В v0.4 также добавляются:
- Селектор активных команд (мультикомандность) — переключение между командами, в которых состоит пользователь.
- Личный инбокс игрока: входящие приглашения от команд, мои исходящие заявки + CTA «Подать заявку в команду» из списка с поиском.

## Связанные файлы
- `src/app/(tabs)/profile/page.tsx` — личный профиль (v0.4 — переписывается под новую модель)
- `src/app/(tabs)/squad/[user_id]/page.tsx` — публичный профиль (с двумя режимами для игрока и организатора)
- `src/app/(tabs)/squad/[user_id]/edit/page.tsx` — редактирование публичного профиля организатором
- `src/app/api/me/route.ts` — данные пользователя и `memberships[]`
- `src/app/api/teams/route.ts`
- `src/app/api/teams/me/members/route.ts`
- `src/store/active-team.ts` + `src/lib/api-client.ts` (хедер `X-Team-Id`) — мультикомандность
- `src/lib/team-link.ts` — построение invite-ссылки
- `src/lib/bot.ts` — handler deeplink

# Эпик: Финансы

## Цель
Учёт сборов и долгов команды. Никаких онлайн-оплат на PoC — только учёт.

## Фичи

### v0.1
- **Экран «Деньги».** Общий баланс команды (income − expense). Список последних транзакций. Список должников (с суммой долга).
- **Добавление транзакции вручную.** Тип (`income` / `expense` / `player_payment` / `player_debt`), сумма, описание, привязка к событию (опционально), к игроку (опционально).
- **Долг по игроку = `cost_per_player` события − `paid_amount` в attendance** для всех событий, где игрок пришёл и не оплатил полностью.
- **Привязка оплаты к событию.** На вкладке «Оперативная» страницы события (см. [roster-day.md](roster-day.md)) оплата создаёт `finance_transaction` (type=`player_payment`).

### v0.2
- Прогноз: «На следующие 4 недели запланировано N тренировок × M ₽ = X собрать, при текущей явке хватит / не хватит»
- Фильтры по дате / типу
- Экспорт CSV

### post-MVP
- Онлайн-оплата аренды через TG Payments / ЮKassa
- Автозачёт долга при оплате

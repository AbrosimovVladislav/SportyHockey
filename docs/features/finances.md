# Эпик: Финансы

## Цель

Учёт сборов, расходов, долгов и депозитов команды. Никаких онлайн-оплат на PoC — только ручной ввод. Один источник правды (`finance_transactions`), долги/переплаты/депозиты — вычисляемые разрезы поверх ленты.

## Модель

Все деньги команды живут в одной таблице `finance_transactions`. Четыре `type`:

- **`player_payment`** — игрок заплатил команде (есть `user_id`; `event_id` опциональный — если есть, оплата привязана к событию, иначе это депозит).
- **`expense`** — команда потратила деньги наружу. Категория в `category` (`arena / inventory / uniform / other`).
- **`refund`** — команда вернула деньги игроку.
- **`adjustment`** — ручная корректировка баланса игрока организатором.

Дата операции — `occurred_on` (отдельно от `created_at`, чтобы можно было бэкдейтить и планировать будущие аренды).

**Долг по игроку** = ∑ `cost_per_player × showed_up` за прошедшие события − ∑ `player_payment + adjustment − refund` для этого игрока. Положительный итог = игрок должен; отрицательный = команда должна (переплата/депозит).

**Баланс команды** (карточка на хабе) — не голый income−expense, а разбивка:

```
Баланс = На руках − Будущие аренды − Переплаты игроков + Долги игроков
```

## Сделано до v0.5

- **Оплата с экрана события (v0.1).** На вкладке «Оперативная» страницы события `PaymentSheet` создаёт `finance_transaction` с `type=player_payment, event_id`. Это пока единственное место ввода денег.
- **Личные финансы игрока (v0.4).** `PlayerFinanceTab` на `/squad/<user_id>` (для организатора) и `/profile/finance` (для самого игрока) показывают баланс, события с долгом, ленту платежей. Источник — `src/lib/player-finance.ts`.

## v0.5 — раздел «Деньги»

Полноценный раздел организатора. Подробности — в [roadmap/v0.5.md](../roadmap/v0.5.md). Кратко:

- **Хаб `/money`** — баланс-карточка с разбивкой, 3 quick-actions (Оплата игрока / Депозит / Расход), лента последних операций, переходы в 4 подэкрана.
- **Финансовый срез `/money/report`** — отчёт за период (текущий месяц / прошлый / 3 месяца / всё / кастом): итог, поступления и расходы по типам/категориям, изменение долгов и переплат, opening/closing balance.
- **Балансы игроков `/money/players`** — текущий срез по всем игрокам с фильтрами «Все / Должники / С депозитом / Закрыты».
- **Операции `/money/transactions`** — универсальный лог с фильтрами по периоду, типу, категории, игроку, событию. Просмотр/редактирование/удаление одной транзакции через bottomsheet.
- **Аналитика `/money/analytics`** — графики (динамика баланса, сборы по месяцам, расходы stacked по категориям, долги, депозиты) + прогноз на 1/2/3 месяца на основе средней явки.

## Вынесено в post-MVP

- **Онлайн-оплата** аренды через TG Payments / ЮKassa.
- **Авто-зачёт долга** при оплате (без явной привязки к событию).
- **Экспорт CSV / Excel** — оценим спрос после пилотов.
- **Множественные кассы** (наличные / счёт / Тинькофф) — у любительских команд это одна копилка.
- **Двусторонние парные транзакции** для переводов между подкассами.

## Связанные файлы

- `src/app/(tabs)/money/` — экраны раздела (на v0.5).
- `src/app/api/finance/` — API раздела (на v0.5).
- `src/lib/player-finance.ts` — расчёт балансов одного игрока (есть с v0.1, расширяется на v0.5).
- `src/lib/team-finance.ts` — массовый расчёт балансов команды (создаётся на v0.5).
- `src/components/payment-sheet.tsx` — sheet оплаты с экрана события (есть с v0.1, мигрирует на единый компонент на v0.5).
- `src/components/finance-sheet/` — bottomsheet'ы ввода (создаются на v0.5).

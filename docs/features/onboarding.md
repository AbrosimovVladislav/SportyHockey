# Эпик: Онбординг

## Цель
Привести пользователя из бота в Mini App, понять роль, собрать минимум данных. На PoC — один экран.

## Фичи

### v0.1
- **Welcome-экран.** Один экран. Выбор роли (organizer / player), кнопка «Продолжить».
- **Organizer flow.** Поле «Название команды», загрузка лого в Supabase Storage. По «Сохранить» — создаём запись в `teams` + `team_memberships` (role=organizer).
- **Player flow.** Подразумевается, что игрок попал в Mini App по invite-ссылке от организатора (`?startapp=team_<id>`). Если ссылки нет — пустое состояние «Попроси организатора прислать ссылку».
- **Имя пользователя.** Берём из Telegram `initData.user.first_name`, не спрашиваем.

## Не входит в v0.1
- Multi-step онбординг
- Выбор города, амплуа, номера
- Coach-роль

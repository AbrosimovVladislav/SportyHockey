# Эпик: Медиа

## Цель
Хранить фото/видео тренировок и игр. Источник материала для будущего соцшеринга.

## Фичи

### v0.2
- **Медиа на событии.** На странице события вкладка / раздел «Медиа». Игроки и организатор могут грузить фото с тренировки/игры. Хранение — Supabase Storage, signed URLs, доступ только членам команды.
- **Лимиты:** на старте — до N МБ на файл, до K файлов на событие. [TODO: уточнить лимиты]
- **Превью.** Сетка 3×N с тач-открытием в полноразмерный просмотрщик.

### v0.5 (MVP)
- **Общая галерея команды.** Лента всех медиа по событиям, фильтр по дате/событию.
- **Видео.** Конвертация / превью на стороне Supabase Storage. [TODO: проверить лимиты]

# Эпик: Статистика

## Цель
Производная информация по игрокам и команде на основе явки и событий. Отдельной таблицы нет — считается из `event_attendances`.

## Фичи

### v0.2
- **Явка %.** Доля событий, на которые игрок пришёл, из тех, на которые звали.
- **Сводка по игроку** (на карточке в составе): явка, оплаты вовремя.

### v0.5 (MVP)
- Голы / пас (агрегация из `event_attendances.goals`, `.assists`)
- Топы (лучший по явке, лучший по очкам)
- Динамика за период (месяц/сезон)

### post-MVP
- Внутренний рейтинг игрока (формула на основе явки, статов, оплат)
- Дашборд тренера

## Не делаем
- Отдельную таблицу `player_stats`. Всё считается из `event_attendances` через materialized views или RPC, если станет тяжело.

# Эпик: Главный экран

## Цель
Первое, что видит пользователь при открытии Mini App. Дайджест — что прямо сейчас важно: ближайшее событие, быстрые действия, ключевая статистика команды.

Главная — первый таб «Команда» (`/(tabs)/page.tsx`). До v0.6 здесь была пустая `Screen`-заглушка.

## Структура (v0.6)

Сверху вниз:

1. **Шапка** — логотип команды + название, иконка-колокольчик справа (заглушка до отдельного эпика уведомлений).
2. **Карточка ближайшего события** — фон-картинка, бейдж типа («Ближайшая тренировка» / «Ближайшая игра»), для игры — пара «наша команда vs соперник» (логотип + название с каждой стороны; для соперника — щит-плейсхолдер с инициалами), дата · время, локация, три метрики (явка / взнос / места), CTA «Открыть событие».
3. **Quick actions 2×2** — четыре важных действия. Набор зависит от роли:
   - **Organizer:** Отметить оплату · Собрать состав · Чат команды · Создать событие.
   - **Player:** Проголосовать · Мой баланс · Календарь · Моя статистика.
4. **Ключевая статистика** — карточка с тремя табами:
   - **Топ-5 игроков** — топ по очкам (Г + П) **только в играх**.
   - **Последний матч** — счёт + ассисты + минуты удаления (без бросков/вбрасываний/сэйвов — этих метрик у нас нет).
   - **Команда** — матчей, тренировок, побед, заброшено, пропущено, финансовый баланс.

### v0.1
- **Заглушка.** Экран существует, но пустой — на момент v0.1 главная не была приоритетом.

### v0.6 (MVP — основной приоритет эпика)
- Каркас главной + карточка ближайшего события (адаптивная под тренировку/игру) — итерация 62.
- Quick actions для organizer — итерация 63.
- Блок «Ключевая статистика» с тремя табами — итерация 64.
- Quick actions для player — итерация 65.
- Полная обкатка MVP (включая финансы v0.5) на пилотной команде — итерация 66.

### post-MVP
- Виджеты, настраиваемая сетка.
- Уведомления-баннеры (информация от бота — внутри Mini App, через колокольчик).
- Раздельные фоны training / game в карточке события.
- Логотип соперника (загрузка `events.opponent_logo_url`).
- На главной игрока — личные числа явки в карточке события вместо «N из M идут».

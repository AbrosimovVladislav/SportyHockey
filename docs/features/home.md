# Эпик: Главный экран

## Цель
Первое, что видит организатор/игрок при открытии Mini App. Дайджест — ближайшее, важное, требующее действия.

## Фичи

### v0.1
- **Заглушка.** Экран существует, но показывает «Скоро — пока перейди на События». Чтобы не задерживать PoC.

### v0.5 (MVP — основной приоритет эпика)
- **Для organizer:** ближайшее событие, явка по нему, долги, требующие внимания (новые голоса, просроченные оплаты).
- **Для player:** ближайшее событие с кнопкой быстрого голосования, мой долг, моя явка %.

### post-MVP
- Виджеты, настраиваемая сетка
- Уведомления-баннеры (информация от бота — внутри Mini App)

# Эпик: Лиги — post-MVP

## Цель
Взаимодействие команды с лигой / турниром. На PoC и MVP — вне скоупа.

## Фичи (post-MVP)

- Регистрация команды в лиге
- Расписание матчей лиги (импорт извне / ручной ввод)
- Турнирная таблица
- Уведомления о матчах лиги через бот
- Связь events ↔ league_match для подсчёта статов

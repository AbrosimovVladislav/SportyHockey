# Эпик: Состав на конкретное событие

## Цель
Оперативная работа организатора непосредственно на событии: кто пришёл, кто оплатил, как разделить команды, статы по матчу.

## Фичи

### v0.1 — три вкладки на одной странице

- **Вкладка «Оперативная».**
  - Список игроков, проголосовавших `+` или `?`.
  - Чекбокс «Пришёл» (`event_attendances.showed_up`).
  - Поле «Оплатил» (сумма → `paid_amount` + создаём `finance_transaction` type=`player_payment`).
  - Сводка наверху: «Пришло 12, оплатили 10, долг 2 500 ₽».

- **Вкладка «Деление».**
  - Для тренировки — рядом с каждым пришедшим две кнопки «Белые / Тёмные», запись в `event_attendances.team_color`.
  - Подсчёт количества с каждой стороны.
  - Для игры — заглушка «Будет позже» (другое разделение, пока не описано).

- **Вкладка «Статистика».**
  - На PoC — минимум: поля «Голы» и «Передачи» рядом с каждым пришедшим (`goals`, `assists`).
  - Полноценно — v0.5 ([stats.md](stats.md)).

### v0.2+
- Drag-and-drop деления игроков по командам
- Авто-баланс по рейтингу
- Расширенные статы (буллиты, минуты на льду)

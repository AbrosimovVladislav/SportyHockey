# Эпик: Площадки

## Цель
Справочник площадок команды для быстрого выбора при создании события.

## Фичи

### v0.1
- Не входит. Площадка вводится свободным текстом в форме события (`events.venue_text`).

### v0.2
- **Список площадок** на странице «Профиль» → раздел «Площадки».
- **Создание площадки**: название, адрес, заметки.
- **Выбор площадки** в форме создания события — селект из списка. Старое поле `venue_text` становится fallback для импорта/совместимости.

### post-MVP
- Карта площадок
- Расписание занятости (если несколько команд используют одну площадку)
- Онлайн-оплата аренды через приложение

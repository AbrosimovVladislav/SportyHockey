# Эпик: Площадки

## Цель
Справочник площадок команды для быстрого выбора при создании события + автоподстановка стоимости с игрока.

## Фичи

### v0.1
- ✅ Таблица `venues` со схемой `{ id, team_id, name, address, notes, default_cost_per_player, created_at }` — последняя колонка добавлена миграцией `venues_default_cost_per_player`. Один тестовый сид «Большая арена» (1000 ₽ с игрока) на существующую команду.
- ✅ `GET /api/venues` — список площадок команды (организатор и игроки получают одинаковый).
- ✅ **Выбор площадки** в форме `/events/new` через `BottomSheet`; единственная площадка автовыбирается. `events.venue_id` (FK на `venues.id`) стал обязательным для новых событий; старое `events.venue_text` остаётся fallback для отображения legacy-данных.
- ✅ **Авто-взнос с игрока**: backend подставляет `events.cost_per_player = venue.default_cost_per_player`, если форма не передала явный override.

### v0.3
- ✅ **Домашняя площадка команды** — `teams.default_venue_id` (итерация 41). Выбирается в `/squad/settings` → вкладка «События и финансы», подставляется при создании события.

### post-MVP
- **Отдельный экран со списком площадок** — фото, адрес, заметки, дефолтный взнос. Изначально планировалось в v0.4 (раздел «Профиль»), вынесено в [post-MVP](../roadmap/post-mvp.md) — не дотягивается до приоритета MVP; место в навигации (раздел «Команда»? отдельный таб? часть «Профиля»?) определим позже.
- **Карточка площадки**: история проведённых на ней событий команды.
- **CRUD площадок**: создание/редактирование (название, адрес, заметки, дефолтный взнос).
- **Карта площадок**.
- **Расписание занятости** (если несколько команд используют одну площадку).
- **Онлайн-оплата аренды** через приложение.

# Эпик: Социальный шеринг

## Цель
Превращать события и медиа в публичный контент. Помочь командам расти.

## Фичи

### v0.5 (MVP)
- **Постер события.** Генерация изображения с деталями (тип, дата, площадка, стоимость, кто играет). Шаринг через нативный share.
- **Публичное событие.** При создании события `visibility = public`. Появляется страница-лендинг с описанием.
- **Постинг в Instagram.** Edge Function берёт фото из медиа события + caption и публикует через Instagram Graph API.

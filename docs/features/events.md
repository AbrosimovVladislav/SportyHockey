# Эпик: События

## Цель
Создание, редактирование, просмотр тренировок и игр. Сердце продукта.

## Фичи

### v0.1
- **Список событий (Events screen).** Группировка по «Сегодня / Эта неделя / Дальше». Карточка: тип, дата, время, площадка (текст), сводка явки (`3+ / 2? / 4−`).
- **Создание события.** Форма: тип (тренировка/игра), дата, время начала и конца, площадка свободным текстом, стоимость на игрока, описание. По «Сохранить» → запись в `events` + бот рассылает голосование всем игрокам команды.
- **Страница события (детали).** Шапка: тип, дата/время, площадка, описание. Блок явки (см. [voting-attendance.md](voting-attendance.md)). Плашка перехода на страницу «Состав на событие» (см. [roster-day.md](roster-day.md)). Заглушка «Медиа».
- **Редактирование события.** Только организатор. При изменении даты/времени — бот пушит обновление каждому проголосовавшему.
- **Отмена события.** Soft-delete (`status = cancelled`), рассылка отмены через бот.

### v0.2
- Выбор площадки из справочника (см. [venues.md](venues.md))
- Календарный вид (toggle «Список / Календарь»)
- Дубликат события («Повторить как в прошлый раз»)

### v0.5+
- Публичные события (`visibility = public`), лендинг события
- Серии тренировок (recurring)

## Не входит на PoC
- Серии / recurring
- Календарный вид

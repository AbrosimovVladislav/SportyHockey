# Эпик: Звенья (lineup) — post-MVP

## Цель
Полноценная расстановка пятёрок и звеньев — хоккейная специфика. Текущее «деление белые/тёмные» — это упрощённая форма; полноценный lineup — это уровни звеньев, амплуа, ротация.

## Фичи (post-MVP)

- Создание звеньев на событие (5 игроков × N звеньев)
- Drag-and-drop UI расстановки
- История звеньев по сезону
- Авто-баланс по рейтингу
- Печать / экспорт расстановки для тренера

## Открытые вопросы
- Назвать сущность `lineup` или иначе? (Пользователь не уверен в названии.)
- Связь с `event_attendances` или отдельная таблица `lineups` + `lineup_slots`?
- Деление белые/тёмные при наличии lineup — отдельная фича или генерируется из звеньев?

# v0.2 — Команда

**Цель:** закрыть раздел «Состав» полноценно, по аналогии с тем, как v0.1 закрывает раздел «События». Расширенный профиль команды, профиль игрока с историей участия и статами, управление членством, справочник площадок.

**Итерации:** TBD — наполнение зафиксируем после завершения v0.1 и сбора фидбека пилотов.

---

## Направления (без детализации до подпунктов)

### Команда и членство

Эпик: [features/team.md](../features/team.md).

- Редактирование профиля команды (название, лого, контакты, соцсети).
- Промоут игрока до организатора + удаление игрока из команды (с подтверждением).
- Просмотр и редактирование атрибутов игрока (амплуа, номер, фото) организатором.

### Профиль игрока

Эпик: [features/team.md](../features/team.md).

- Отдельный экран игрока (тап по карточке в `/squad`).
- История участия в событиях (% явки, последние события, голы/передачи — после v0.1.18).
- Долги и оплаты игрока (read-only, без редактирования транзакций — это в v0.3).

### Площадки

Эпик: [features/venues.md](../features/venues.md).

- Раздел «Площадки» в профиле организатора.
- CRUD площадок: API `GET/POST/PATCH/DELETE /api/venues[/...]`, форма редактирования (название, адрес, заметки, стандартные стоимости).
- Селект площадки из списка в форме создания события уже есть с v0.1 — здесь дорабатываем редактирование.

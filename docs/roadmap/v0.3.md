## Направления (без детализации до подпунктов)

### Учёт

- Экран `/money`: баланс команды (income − expense), список последних транзакций.
- Add transaction modal: все типы (`income / expense / player_payment / player_debt`), сумма, описание, опциональная привязка к event/user.
- API `GET/POST /api/finance`.
- Возвраты — парная транзакция.

### Должники

- Расчёт должников из событий (`showed_up=true AND paid < cost_per_player`).
- API `GET /api/finance/debts` + блок «Должники» на `/money`.

### Прогноз и фильтры

- Прогноз поступлений на 4 недели вперёд (запланированные события × `cost_per_player` × ожидаемая явка).
- Фильтры списка транзакций (по типу, по диапазону дат, по событию/игроку).

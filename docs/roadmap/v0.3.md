### Настройки команды

Эпик: [features/team.md](../features/team.md).

- Настройки на уровне команды (определим состав на handoff): параметры команды, роли, доступы.
- **Фото для шапок (`DarkHeader`: «Состав», «Расписание», событие).** Организатор загружает картинку для блоков шапки своей команды; сейчас зашиты статичные `/team.png`, `/bus.png`, `/arena.png`. Кадрировщик с фиксированной рамкой (как `AvatarCropper` из 28.4), на выходе нормализованная картинка.
  - Блок шапки рендерится `cover` на всю ширину × `252px + опасная зона` (≈ квадрат, чуть шире, зависит от устройства). Рекомендация загрузки: **4:5 (вертикальное), субъект по центру с запасом ~20% сверху/снизу, минимум ~1440×1800 px, JPG/WebP.** При 4:5 картинка всегда показывается на всю ширину (по бокам не режется), подрезается только верх/низ.
  - На усмотрение: жёстко зафиксировать соотношение блока шапки (например 4:5), чтобы высота не плавала по устройствам и кадр был одинаковым у всех.

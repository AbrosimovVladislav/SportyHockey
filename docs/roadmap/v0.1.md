### Доработки (база и форма создания события)

- ✅ 13.1 Миграции БД (применены `attendees_payment_arena_jersey`):
  - `team_memberships`: добавлены `jersey_number int NULL`, `position text NULL CHECK (position IN ('forward','defender','goalie'))`.

## ✅ Итерация 14.5 — Звенья + UX-ревизия Состава

Эпики: [features/lineup.md](../features/lineup.md), [features/roster-day.md](../features/roster-day.md). Подняли «звенья» из post-MVP в PoC: на тренировке организатор раскидывает игроков по звеньям атаки и парам защиты в каждой команде. Параллельно переработали карточку игрока и интеракцию drag-and-drop по фидбеку.

Принципиальные решения:
- три вкладки внутри `/events/[id]/lineup`: **«Команды» / «Светлые» / «Тёмные»**. Для **игры** показывается только «Команды» — звенья только на тренировке;

- слот = одна позиция. Один игрок — в одном слоте на команду. Снять из слота — drop в «Запасные»;
- целостность с командами: убираешь игрока из команды → каскад чистит его строки в `event_lines` (и в обеих командах — на всякий случай в `lineup`-route).

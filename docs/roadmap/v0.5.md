## Направления (без детализации до подпунктов)

Раздел «Профиль» собирает доступ к профилю команды, селектору команд, личному профилю игрока и настройкам.

### Профиль команды

- Расширенная карточка команды (название, лого, описание, контакты, ссылки на соцсети).
- Общая галерея команды живёт в разделе «Команда» → секция «Медиа» ([v0.3](v0.3.md)); здесь — только ссылка/превью.

### Личный профиль игрока

Эпик: [features/team.md](../features/team.md). (Приватная часть профиля, переехала из v0.2.)

- Свой профиль — игрок редактирует сам (имя, фото, дата рождения, контакты, примечание).
- Свои командные поля (амплуа, позиция, номер) — игрок правит сам; `tier` и членство остаются за организатором (v0.2).
- Загрузка фото в Supabase Storage.
- Расчётные поля (статистика, посещаемость, финансы) — никто не редактирует напрямую.

### Селектор команд

- Переключение между командами, в которых состоит пользователь.

### Настройки

- Возможно — переезд части настроек из текущего таба «Ещё» (`/profile`) в раздел «Профиль» (определим на handoff).

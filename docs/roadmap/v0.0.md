## Итерация 1 — Базовая инициализация

- 1.1 `git init` + создать приватный GitHub-репозиторий `sporty-hockey`
- 1.2 Создать Next.js 15 app: `pnpm create next-app apps/miniapp --typescript --app --tailwind=false --no-eslint --src-dir`
- 1.3 Установить runtime-зависимости: `pnpm add @telegram-apps/sdk-react zustand @supabase/supabase-js @tanstack/react-query grammy zod`
- 1.4 Установить dev-зависимости: `pnpm add -D @types/node`
- 1.5 Создать структуру папок `src/{app,components,features,hooks,lib,store,theme,types,i18n}/` по [ARCHITECTURE.md](../ARCHITECTURE.md)
- 1.6 `tsconfig.json`: `"strict": true`, alias `"@/*": ["./src/*"]`
- 1.7 Скрипты `pnpm typecheck` (`tsc --noEmit`) и `pnpm build` работают
- 1.8 `.env.example` в репо со всеми переменными (`SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `BOT_TOKEN`, `BOT_WEBHOOK_SECRET`); `.env`* в `.gitignore`

- 3.1 Создать проект Supabase `sporty-hockey`, сохранить URL и service-role ключ
- 3.2 `pnpm dlx supabase init` в корне + `supabase link --project-ref ...` + `supabase start` (локальный стек)
- 3.3 Миграция `supabase/migrations/0001_init.sql` со всеми 8 таблицами из [ARCHITECTURE.md](../ARCHITECTURE.md#модель-данных-v01)

- 3.6 Генерация типов: `supabase gen types typescript --linked > apps/miniapp/src/types/db.ts`

## Итерация 4 — Бот + auth

- 4.1 Создать бота через @BotFather, получить токен, сохранить в `BOT_TOKEN`
- 4.2 `/newapp` в BotFather — привязать Mini App к домену Vercel (placeholder, обновим после деплоя)
- 4.3 `lib/bot.ts` — grammy Bot instance с обработчиком `/start` (приветствие)
- 4.4 `src/app/api/bot/route.ts` — Telegram webhook handler через `webhookCallback(bot, 'std/http')`; проверка `X-Telegram-Bot-Api-Secret-Token`
- 4.5 Установить webhook: `pnpm run set-webhook` (curl к `api.telegram.org/bot<TOKEN>/setWebhook` с `secret_token`)
- 4.6 `lib/telegram-verify.ts` — HMAC-проверка `initData` через `BOT_TOKEN`
- 4.7 `lib/auth.ts` — `requireUser(request)`: читает `Authorization: tma <initData>`, валидирует HMAC, upsert в `users`, возвращает `user_id` (или 401)
- 4.8 `lib/api-client.ts` (фронт) — типизированный fetch, автоматически прикладывает `Authorization: tma <initData>` к каждому запросу

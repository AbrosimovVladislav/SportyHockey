# SportyHockey — Product Brief

## Что это

Telegram Mini App + бот для организаторов любительских хоккейных команд. Заменяет связку «Excel + Google-таблицы + чат» одним местом, где ведутся события, явка, финансы, состав, медиа.

## Целевая аудитория

Организаторы и их любительские команды. Стартовый рынок — Санкт-Петербург, ~250–300 команд.

## Ключевая ставка PoC

Большинство игроков не поставит app. Поэтому голосование на событие работает прямо в боте (inline-кнопки `+/?/−`) без открытия Mini App. Mini App — для организатора (тяжёлый клиент); бот — для игрока (тонкий клиент). При этом player **может** зайти в Mini App — это подготовка к нативному app.

## Ключевые сущности

- **Team** — команда; всё привязано к команде
- **User** — пользователь по Telegram ID
- **TeamMembership** — связь user ↔ team + роль (`organizer` / `player`)
- **Event** — тренировка или игра (тип, дата, площадка, стоимость)
- **EventAttendance** — голос игрока, факт явки, оплата, статы (голы, пас), деление «белые/тёмные»
- **Venue** — площадка (v0.2+)
- **FinanceTransaction** — сборы, расходы, долги
- **MediaItem** — фото/видео (v0.2+)

## Навигация (5 нижних табов)

1. **Главное** — дайджест (заглушка на PoC, основной приоритет в v0.5)
2. **События** — список + календарь; страница события; страница состава на событие
3. **Деньги** — учёт сборов, долги, прогнозы (v0.2)
4. **Состав** — игроки команды, роли, приглашения
5. **Профиль** — команда (название, лого), площадки (v0.2), настройки

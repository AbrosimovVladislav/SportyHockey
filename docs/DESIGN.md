# SportyHockey — Design System (DRAFT)

> ⚠️ Это рабочий черновик. Конкретные значения уточняются по мере того, как пользователь скидывает экраны.
>
> Базовое правило: **используем переменные темы Telegram**, чтобы Mini App автоматически адаптировался под светлую/тёмную тему пользователя. Свои цвета — только там, где TG-палитры недостаточно.

## Принципы

1. **Спортивный, динамичный, не «корпоративный».** Сильная типографика, плотная информационная сетка.
2. **Native-feel внутри Telegram.** Уважаем TG-цвета, тач-таргеты, жесты, нативные `BackButton`/`MainButton`.
3. **Информация важнее украшений.** Списки игроков, цифры, статусы — без скевоморфизма.
4. **Чёткое разделение ролей.** UI организатора и игрока имеют общий язык, но разное насыщение функциями.

## Цвета

Используем CSS-переменные Telegram + дополнительные акценты для семантических состояний.

## Типографика

Шрифт: системный (`-apple-system, BlinkMacSystemFont, "Inter", sans-serif`). Telegram не позволяет менять шрифты — не сопротивляемся.

| Стиль | Размер / line-height | Вес | Назначение |
|-------|----------------------|-----|------------|
| Display | 28 / 32 | 700 | Заголовки экранов |
| Title | 20 / 26 | 600 | Заголовки секций |
| Body | 16 / 22 | 400 | Основной текст |
| Caption | 13 / 18 | 500 | Подписи, метки |
| Mono | 14 / 20 | 500 | Цифры, время, счёт |

## Отступы (Spacing)

Шкала 4-пиксельная: `XS=4, S=8, M=12, L=16, XL=24, XXL=32, XXXL=48`.

Константы — `Spacing.S`, `Spacing.M` из `src/theme/spacing.ts`. **Запрет:** `marginTop: 14` — должно быть `Spacing.M` (16).

## Скругления (Radius)

`SM=8, MD=12, LG=16, FULL=999`. Кнопки → MD. Карточки → LG. Аватары → FULL.

## Компоненты (черновой список)

- `Button` — варианты `primary | secondary | ghost | danger`, размеры `sm | md | lg`
- `Input` — текст, `clearButton`, `error` state
- `Card` — секция со скруглением LG, фон `--bg-secondary`
- `Screen` — обёртка экрана с safe area и фоном `--bg`
- `TabBar` — нижняя навигация, 5 вкладок
- `BackButton` — биндинг к нативному `BackButton` Telegram
- `MainButton` — биндинг к `MainButton` (внизу, например «Сохранить»)
- `Avatar` — круг + initials
- `Chip` — статус (going / maybe / not_going)
- `EmptyState` — заглушка для пустых списков
- `VoteButton` — три варианта голоса (+ / ? / −), большой тач-таргет

## Антипаттерны

- Хардкод hex-цветов в компонентах — только через тему
- Произвольные числа в `padding/margin` — только из `Spacing`
- Кастомные SVG-иконки, дублирующие TG-нативные
- Свои back-кнопки, не использующие `BackButton` SDK
- Тач-таргеты < 44px
- Тёмная тема как «инвертированные цвета» — переменные TG уже всё делают

## Тёмная тема

Не требует отдельной палитры — все цвета через TG-переменные. Тестируется при переключении темы в Telegram.

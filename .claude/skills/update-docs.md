description: Обновление документации после завершения фичи.
---

После завершения фичи:

1. `docs/README.md` — обнови статус фичи в таблице эпиков, если эпик закрыт — отметь ✅
2. `docs/features/<эпик>.md`:
   - актуализируй описание
   - в «Связанные файлы» добавь реальные пути
   - удаляй `[TODO]`-маркеры, которые закрылись
3. `docs/ROADMAP.md`:
   - перенеси фичу из «План» в «Сделано» в соответствующей версии
   - если закрыта вся версия — отметь дату релиза
4. Если изменилась схема БД — обнови SQL-блок в `docs/ARCHITECTURE.md` и добавь миграцию в `supabase/migrations/`

Кратко. Не раздувай. Не дублируй описания между файлами.

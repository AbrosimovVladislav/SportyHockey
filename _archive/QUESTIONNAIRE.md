# Опросник нового проекта

> **Для Claude Code:** прочитай этот файл и проведи интервью с пользователем.
> Задавай вопросы группами. После каждой группы предлагай варианты выбора.
> Когда все группы пройдены — заполни файлы проекта по шаблонам из INIT.md.

---

## Как проводить интервью

1. Задавай вопросы ГРУППАМИ (см. ниже). Одна группа за раз.
2. Внутри группы задавай по 1-2 вопроса, предлагай варианты где возможно.
3. Если пользователь отвечает свободным текстом — извлекай структуру сам (экраны, сущности, роли).
4. Не спрашивай то, что пользователь уже сказал ранее в разговоре.
5. После всех групп покажи итоговую сводку и спроси подтверждение.
6. После подтверждения — запусти генерацию файлов по INIT.md.

## Группа 2: Стек и технологии

- UI фреймворк

  - Дефолт: React Native + Expo

- Backend
  - Варианты: Supabase (рекомендуется для старта) / Firebase / Custom Node.js + PostgreSQL / Другое
  - Дефолт: Supabase

- Авторизация
  - Варианты: Email + password / Google OAuth / Apple Sign In / Telegram / Комбинация
  - Дефолт: Email + password

## Группа 4: Продукт

Это свободная часть. Попроси пользователя описать продукт своими словами:

> "Опиши продукт как видишь: какие основные экраны, что пользователь может делать,
> какие роли (если есть). Не нужно быть точным — я структурирую сам."

Из ответа извлеки:
- **Сущности** (User, Team, Order, etc.)
- **Экраны / эпики** (группы функциональности)
- **Роли пользователей** (если упоминаются)
- **Ключевые фичи** для v1

Покажи извлечённую структуру и спроси: "Верно? Что добавить/убрать?"

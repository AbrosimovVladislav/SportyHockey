## Что сгенерировать

На основе ответов пользователя создай/обнови следующие файлы:

### 1. `CLAUDE.md` (корень проекта)
Инструкции для Claude Code. Содержит:
- Название + одна строка описания
- Старт сессии — ОБЯЗАТЕЛЬНО включи этот блок:
  ```
  ## Старт сессии
  При начале работы прочитай ТОЛЬКО эти файлы:
  1. Этот файл (CLAUDE.md)
  2. docs/PRODUCT_BRIEF.md
  3. docs/DESIGN.md
  4. docs/ROADMAP.md

  НЕ читай docs/README.md, docs/features/, QUESTIONNAIRE.md, INIT.md целиком.
  В README.md и features/ заходи ТОЛЬКО когда работаешь над конкретной фичей — 
  открывай только нужный раздел/файл.
  ```
- Стек (из ответов)
- Конвенции кода (стандартные для выбранного стека)
- Запреты (git, any, секреты, удаление файлов без подтверждения)
- Команды (npm/yarn в зависимости от стека)
- Workflow: Plan → Implement → Review (коротко, 3-5 строк на каждый)
- После фичи: обновить доки

Максимум 120 строк. Без воды.

## Генерация v0.0 — Setup Roadmap

v0.0 — это "нулевая версия", которая создаёт пустое работающее приложение.
Сгенерируй на основе ответов:

### Обязательные шаги (всегда):
1. Инициализация проекта (expo init / flutter create / etc.)
2. Структура папок по ARCHITECTURE.md
3. Настройка TypeScript / линтера
4. Настройка навигации (Expo Router / GoRouter / etc.)
5. Создание базовых UI компонентов (Button, Input, Card) — пустые заглушки
6. Тема: файлы цветов, типографики, отступов
7. Пустые экраны-заглушки для всех табов
8. Первый запуск на симуляторе — убедиться что всё работает

### Условные шаги (на основе ответов):

**Если Supabase:**
- Создать проект в Supabase Dashboard
- Скопировать URL и anon key в .env
- Настроить supabase client (`src/lib/supabase.ts`)
- Создать таблицы (SQL миграции из сущностей)
- Настроить RLS policies
- Настроить Auth

**Если Firebase:**
- Создать проект в Firebase Console
- Скачать google-services.json / GoogleService-Info.plist
- Настроить Firebase SDK

**Если push-уведомления:**
- Настроить Expo Notifications
- Создать Edge Function / Cloud Function для отправки

**Если Stripe / RevenueCat:**
- Создать аккаунт, получить ключи
- Настроить серверную часть (Edge Function)

**Если Telegram бот:**
- Создать бота через @BotFather
- Получить token
- Создать Edge Function / webhook

**Если EAS Build:**
- `eas init`
- `eas build:configure`
- Настроить профили (development, preview, production)

**Если Analytics:**
- Создать проект в выбранном сервисе
- Установить SDK
- Настроить базовые события

### Формат шагов в ROADMAP:
Каждый шаг — строка в таблице:
```
| # | Задача | Статус | Инструкция |
|---|--------|--------|------------|
| 1 | Expo init | 📋 | `npx create-expo-app squad --template blank-typescript` |
| 2 | Supabase project | 📋 | Перейти в supabase.com → New Project → скопировать URL и key |
```

Поле "Инструкция" — конкретная команда или действие. Не "настроить Supabase", а ЧТО ИМЕННО сделать.

## Правила генерации

- **Лаконичность.** Не более 3 предложений на описание фичи. Не более 120 строк на CLAUDE.md.
- **Без воды.** Не пиши "это важный файл". Просто пиши контент.
- **Конкретика.** Вместо "настроить backend" → "создать проект в Supabase Dashboard, скопировать URL в .env".
- **Структура из ответов.** Если пользователь назвал 4 экрана — в проекте 4 экрана, не 8.
- **Draft-пометки.** Всё что требует уточнения — помечай `[TODO]` или `[DRAFT]`.

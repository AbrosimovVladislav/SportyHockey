# Тест-кейсы: онбординг игрока и приглашение игрока в команду

> Перед тестами с ботом: на Vercel задан `BOT_USERNAME` (реальный юзернейм бота). Иначе invite-ссылка не открывается.

---

## 1. Игрок приходит сам (его не приглашали) и подаёт заявку

1. Игрок впервые открывает приложение → видит экран выбора роли.
2. Жмёт «Я игрок» → открывается форма профиля, имя и Telegram-ник уже подставлены из Telegram.
3. Правит данные при желании, в поиске находит и выбирает **одну** команду.
4. Жмёт «Отправить заявку» → видит экран «Заявка отправлена — ждём подтверждения».
5. Организатор этой команды открывает «Профиль» → видит заявку игрока → жмёт «Принять».
6. Игрок переоткрывает приложение → попадает на главную, он в команде.

---

## 2. Организатор отклоняет заявку игрока

1. Игрок подал заявку (шаги 1–4 из сценария 1), видит «ждём подтверждения».
2. Организатор в «Профиле» жмёт «Отклонить» → заявка пропадает из списка.
3. Игрок переоткрывает приложение → в команду **не** попал, снова на онбординге, может подать заявку заново.

---

## 3. Игрока пригласили, он ещё не в приложении

1. Организатор открывает «Состав» → зелёная кнопка «+» → экран создания игрока.
2. Заполняет данные игрока, включает свитчер «Пригласить в приложение» → жмёт «Создать».
3. Появляется окно со ссылкой и кнопками «Отправить приглашение», «Скопировать», «Готово».
4. Жмёт «Отправить приглашение» → открывается шит «Поделиться» → выбирает чат игрока, отправляет.
5. Игрок (новый Telegram) открывает ссылку → бот пишет «Готово! Открой приложение…».
6. Игрок открывает приложение → онбординг с уже заполненными данными (теми, что вписал организатор).
7. Правит при желании → жмёт «Готово» → попадает на главную, он в команде (без отдельной заявки и аппрува).

---

## 4. Организатор завёл игрока без приглашения

1. Организатор: «Состав» → «+» → заполняет данные.
2. Свитчер «Пригласить в приложение» **выключен** → жмёт «Создать».
3. Окна со ссылкой нет, сразу возврат на состав.
4. Новый игрок виден в списке сразу, на карточке — бейдж «Нет аккаунта».

---

## 5. Заведённого игрока он сам заходит через Telegram (без приглашения)

1. Организатор завёл игрока, **указав его настоящий Telegram-ник** (сценарий 4), приглашение не отправлял.
2. Игрок сам открывает приложение и авторизуется через Telegram (не по invite-ссылке).
3. Ожидаемо: второй профиль **не** создаётся — его Telegram привязывается к заготовке по совпадению ника. В таблице `users` остаётся **одна** запись: ник заведённый организатором + telegram_id из Telegram.
4. Игрок попадает на онбординг с предзаполненными полями (он уже в команде, заявку подавать не нужно) → «Готово» → главная.

---

## 6. Приглашают/заводят игрока, чей ник уже есть в системе (в другой команде)

1. Организатор: «Состав» → «+» → вписывает Telegram-ник игрока, который уже зарегистрирован в другой команде.
2. Жмёт «Создать».
3. Возврат на состав → этот игрок появился в команде. Новая карточка-дубль **не** создаётся.
4. Открыть профиль игрока: его личные данные (имя, дата рождения, хват) — прежние, не перезаписаны данными из формы.

---

## 7. Заводят игрока, который уже в этой команде

1. Организатор: «Состав» → «+» → вписывает ник игрока, который уже состоит в его команде → «Создать».
2. Видит ошибку «Этот игрок уже в твоей команде». Игрок не дублируется.

---

## 8. По приглашению переходит человек, у которого уже есть аккаунт

1. Организатор создаёт игрока с приглашением, **не указывая Telegram-ник** (или указывая неверный) → получает ссылку и отправляет её.
2. По ссылке переходит человек, у которого **уже есть** аккаунт в приложении (например, играет в другой команде).
3. Бот пишет «У тебя уже есть аккаунт… попроси организатора добавить тебя в команду» — новый дубль-профиль не создаётся.

---

## 9. Повторный переход по той же ссылке тем же человеком

1. Игрок уже перешёл по приглашению и привязался (сценарий 3).
2. Открывает ту же ссылку ещё раз → бот пишет «Готово! Открой приложение…», ничего не ломается.

---

## 10. Недействительная ссылка-приглашение

1. Открыть ссылку с испорченным или несуществующим кодом игрока.
2. Бот пишет «Ссылка-приглашение недействительна. Попроси организатора прислать новую».

---

## 11. Игрок выбирает роль «Организатор» и создаёт команду

1. Человек впервые открывает приложение → выбор роли → «Я организатор».
2. Вводит название команды → жмёт «Создать».
3. Попадает на главную как организатор новой команды.
